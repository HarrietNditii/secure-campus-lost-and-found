# Secure Campus Lost and Found System

## Project Overview

The Secure Campus Lost and Found System is a web application designed to help university students and staff report lost belongings, register found items, search for property, and submit ownership claims.

The goal is to make it easier to reunite people with their belongings while promoting accountability and secure handling of claims.

## Objectives

- Allow users to report lost and found items.
- Provide searchable listings of reported items.
- Allow users to submit claims for items they believe belong to them.
- Enable administrators to review claims and manage listings.
- Maintain traceability of changes through Git and GitHub.

## Planned Technology Stack

- Frontend: React, TypeScript and Tailwind CSS.
- Backend: Node.js and Express.
- Database: PostgreSQL.
- Version control: Git and GitHub.
- Automated checks: GitHub Actions.

## Software Configuration Management

This project uses GitHub Flow. The `main` branch contains the stable version, while short-lived feature and bug-fix branches are used to develop changes.

Issues will track requirements and defects. Pull requests will document proposed changes, and testing will be performed before merging into `main`.
